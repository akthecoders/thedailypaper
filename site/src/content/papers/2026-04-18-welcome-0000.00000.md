## TL;DR

This is a placeholder entry so the site has something to render on its first deployment. Once the daily pipeline runs, real paper explainers will take this spot. Feel free to delete this file after your first genuine paper lands.

## Why this matters

An empty Astro content collection would cause the homepage to have nothing to display. Shipping one seed entry lets you verify the build, deployment, typography, and layout before the pipeline's first real run.

## How to remove this

Once a real paper lands in `site/src/content/papers/`, you can delete this file:

```bash
rm site/src/content/papers/2026-04-18-welcome-0000.00000.md
git commit -am "remove seed entry"
git push
```

## What's coming

Every morning at 7 AM IST, the pipeline will:

1. Pull new papers from arXiv across cs.LG, cs.AI, cs.CL, cs.DS, q-fin.TR, q-fin.CP, and stat.ML
2. Score them by citation velocity, code availability, and category weight
3. Pick the single most interesting one against the configured interests
4. Generate a reimplementation-grade write-up
5. Commit it to this repo, rebuild the site, and ping Telegram
